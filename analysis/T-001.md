# calculator.py 除数为 0 时崩溃

## 结论
三处除法都缺少除零保护，任何一次 `b == 0` 都会让整个调用栈崩掉。

## 根因

| 位置 | 代码 | 问题 |
|---|---|---|
| `src/calculator.py:7` | `return a / b` | `b == 0` 时 `ZeroDivisionError` |
| `src/calculator.py:17` | `return total / len(numbers)` | 空列表时 `len()` 为 0 |
| `src/calculator.py:22` | `return (part / whole) * 100` | `whole == 0` 时崩溃 |

复现：`divide(10, 0)` 抛 `ZeroDivisionError: division by zero`；`average([])` 同样。

## 修复建议

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b


def average(numbers):
    if not numbers:
        return 0.0
    return sum(numbers) / len(numbers)


def percent(part, whole):
    if whole == 0:
        return 0.0
    return (part / whole) * 100
```

## 风险与注意
- `divide` 选择**抛异常**而不是返回 0：除零是调用方的逻辑错误，静默返回 0 会掩盖 bug。
- `average([])` 返回 `0.0` 是业务约定，若语义要求"无定义"，应改为 `raise ValueError`。
- `percent` 返回 0.0 而非 NaN，便于前端直接展示。

- `src/list_utils.py:7` `items[-n - 1:]` 存在 off-by-one，取到 n+1 个元素。
