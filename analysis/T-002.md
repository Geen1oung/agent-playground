# 希望 calculator.py 增加标准差计算

## 结论
可以实现，但必须显式处理空列表和单元素列表，否则会除零或产生 `math.sqrt` 负数域错误。

## 根因（现状缺口）
`src/calculator.py` 目前只有 `divide` / `average` / `percent`，没有任何方差/标准差能力。
直接照搬公式 `sqrt(sum((x-mean)^2)/n)` 时：
- `n == 0`（空列表）→ 除零
- `n == 1` → 方差为 0，虽不报错但语义上"标准差"无意义

## 修复建议

```python
import math


def stddev(numbers):
    """总体标准差。空列表或单元素返回 0.0。"""
    n = len(numbers)
    if n < 2:
        return 0.0
    mean = sum(numbers) / n
    variance = sum((x - mean) ** 2 for x in numbers) / n
    return math.sqrt(variance)
```

## 风险与注意
- 上面是**总体标准差**（除以 n）。若要**样本标准差**，分母改为 `n - 1`，且 `n < 2` 时仍需返回 0.0。
- 浮点累加在大数据集上会有精度损失，需要更严谨可用 `statistics.pstdev` 标准库替代。
- 返回 0.0 而不是抛异常，是为了让 `percent`、`average` 这类调用链保持连续。

## 建议的后续
若本 ticket 通过，可考虑把 `average` 内部改为 `sum(numbers) / len(numbers)`，与 `stddev` 的均值计算保持一致，减少重复逻辑。
